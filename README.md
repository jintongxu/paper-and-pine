# Paper & Pine

A bright blue-and-white Obsidian theme for technical notes, documentation, and long reading sessions.

## Install in Obsidian

1. Open **Settings → Appearance → Themes → Manage**.
2. Search for `Paper & Pine` after the theme is published to the community list.

For direct installation from this repository, copy `manifest.json` and `theme.css` into:

```text
<your-vault>/.obsidian/themes/Paper & Pine/
```

Then select **Paper & Pine** in Obsidian's appearance settings.

## Highlights

- Sky-blue and white interface palette
- Current-file path emphasis in the file tree
- Stable outline panel with no delayed active background
- Light technical callouts for commands, output, errors, and tips
- Syntax-aware code colors with a restrained flat code-block style
- Focus-mode CSS foundation via `body.pp-focus-mode`
- Responsive reading width and low-contrast scrollbars

`preview.html` and `style-options.html` contain visual prototypes; they are not required for the Obsidian theme installation.
